Roadmap to SAC: NN Foundations, Reinforcement Learning

One-on-One Lecture Course

[Schedule]

  • Format: One-on-one lecture course, building up from RL fundamentals to Soft Actor-Critic.
  • Prerequisites: Basic probability, linear algebra, and Python.
  • Goal: Derive and understand SAC's core equations from first principles.
  • Materials: Lecture materials will be made publicly available on this website as they are completed.

Overview

This course builds up the theory and machinery needed to understand Soft Actor-Critic (SAC) from first principles. Starting from Markov Decision Processes, we develop value functions, the Bellman equation, and dynamic programming, then transition into deep learning foundations and modern deep reinforcement learning methods — value-based, policy-gradient, and actor-critic approaches — culminating in a full derivation of SAC's core equations.

Schedule

  1. 1. RL Fundamentals + MDP

    9/2 · 12–1am

    Agents, environments, rewards, and the Markov Decision Process formalism that everything else in the course builds on.

  2. 2. State Value Function V(s)

    9/5 · 11–12pm

    Defining how good a state is under a policy, and how returns are discounted over time.

  3. 3. Bellman Equation

    9/6 · 11–12pm

    The recursive relationship that underlies nearly every RL algorithm, for both value functions and action-value functions.

  4. 4. DP (Value/Policy Iteration)

    9/9 · 12–1am

    Solving MDPs exactly with dynamic programming, and how value iteration and policy iteration converge to the optimal policy.

  5. 5. PyTorch + NN Foundations

    9/12 · 11–12pm

    Tensors, autograd, and building/training simple neural networks in PyTorch — the toolkit the rest of the course relies on.

  6. 6. Value-Based RL (Q-Learning), Buffer

    9/13 · 11–12pm

    Learning action values directly from experience, and why replay buffers make this stable enough to work in practice.

  7. 7. Policy Gradients

    10/10 · 11–12pm

    Optimizing a policy directly via gradient ascent on expected return, and the variance problems that motivate later methods.

  8. 8. Actor-Critic, Max Entropy RL

    10/11 · 11–12pm

    Combining value and policy learning, and introducing entropy regularization as a way to encourage exploration.

  9. 9. SAC's Core Equations

    10/14 · 12–1am

    Deriving the soft value function, soft Bellman backup, and the full Soft Actor-Critic objective from the pieces built up so far.

  10. 10. Consolidation + Comparison

    10/17 · 11pm–1am

    Comparing SAC against the value-based and policy-gradient methods covered earlier, and tying the whole course together.

  11. 11. Test

    10/18 · 11pm–1am

    A comprehensive test covering the full course, from MDPs through SAC.
